## Privacy warning

The interview zip contains `interviewee-1.csv`, `interviewee-2.csv`, and
`Activity Notes.xlsx` from a human-subjects study. Treat it as potentially
confidential: confirm the consent/IRB terms before redistributing, quoting, or
reusing the transcripts. See
[`../docs/data-and-privacy.md`](../docs/data-and-privacy.md).
