# Course Notes

These are my course notes, lab reports, and code. I keep them for myself: a
record of what I took and what I wrote down. It isn't a public course, a
template, or a portfolio, and I'm not trying to keep it polished for anyone
else.

Most of it is computer science, mathematics, economics, and business work, plus
some programming practice.

## Before I push

I run `make check`. If I touched Java, C++, or the Python tests, I also run
`make check-code`. It's mostly there to catch broken links and stale paths, not
to prove anything.
